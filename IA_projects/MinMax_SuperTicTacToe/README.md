# Creation of a Minimax algorithm capable of playing Super Tic-Tac-Toe (C Project) 

## Principle of the project 

The first programming language I learned was C in 2023, when I arrived at Centrale Lille. As part of the "Advanced Algorithms and Programming" course, we worked on a project that involved creating a minimax algorithm capable of playing Ultimate Tic-Tac-Toe.

## Ultimate Tic Tac Toe rules 

Super Tic-Tac-Toe is an advanced version of the classic Tic-Tac-Toe game, played on a 3×3 grid of smaller Tic-Tac-Toe boards. Each move determines which small board the opponent must play in next, making the game more strategic and challenging. (more infos on https://en.wikipedia.org/wiki/Ultimate_tic-tac-toe)
